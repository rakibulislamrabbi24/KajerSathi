# Third-party attribution: Bijoy conversion engine

KajerSathi Release 1.0.9 integrates the conversion engine from:

- Repository: https://github.com/abir-ahamed-glitch/10-Bijoy-to-Unicode
- File: js/engine.js
- Upstream README declares the project MIT licensed.
- Upstream engine was validated against its accompanying 192-case conversion suite before integration.

The upstream engine is kept as a separate file at assets/js/kajersathi-bijoy-engine.js. KajerSathi's UI and SutonnyMJ preview remain separate from the conversion implementation.
